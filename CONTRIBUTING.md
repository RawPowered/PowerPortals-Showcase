# Contributing

This is the public-facing PowerPortals product and documentation repository. Please keep contributions limited to approved product copy, setup documentation, release notes, and cleared brand assets.

Do not add plugin source code, installable packages, credentials, API tokens, customer data, private screenshots, or internal development records. Public issues are for documentation and product feedback only; do not use them to report security vulnerabilities or share private information.

Before proposing screenshots or media, remove personal information, CRM records, site URLs that identify a customer, and all credentials. Confirm that the asset is approved for public use.
