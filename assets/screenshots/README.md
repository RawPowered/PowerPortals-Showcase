# Screenshot notes

The portal and intake PNGs in this directory were captured from an isolated PowerPortals test installation on 2026-10-10. The visible project and account details are fictional demonstration data. No production customer records are included.

`customer-hub-concept.svg` is an illustrative, brand-neutral concept created for the public product overview. It is not a capture of a released customer portal.

The Zoho widget previews run the beta widget interfaces with a mocked Zoho SDK and fictional CRM schema, record, and parcel response. They illustrate the current package UI; they do not show live CRM data or claim customer-specific compatibility.
